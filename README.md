# DENV in Ivory Coast

This repository contains all XML files used in our dengue virus analyses.

## Repository Contents

All BEAST XML files used in this study are provided in this repository.

## Tree Files

The empirical tree files referenced by the `denv_phylogeographic` XML files are available for download under the GitHub Releases section of this repository.

To reproduce the analyses, download the corresponding tree files and ensure that the file paths specified in the XML files point to their correct local locations.
